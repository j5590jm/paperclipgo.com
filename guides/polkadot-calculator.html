2. Current DOT Value     = Total DOT Owned × Live DOT Price (via anonymous proxy)
3. Unrealized Gain / Loss  = Current DOT Value − Total USD Paid
4. Return Percentage (ROI) = ((Current DOT Value − Total USD Paid) ÷ Total USD Paid) × 100
5. Scenario Value (Δ%)     = Current DOT Value × (1 + (Scenario Slider % ÷ 100))
